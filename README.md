此仓库存储了2025-2026学年排球社的文件。

	1.排球社工作流程及注意事项
		1.1 百团大战
			1.1.1 百团大战需要报名，社团社长群中会通知，及时填表。
			1.1.2 百团大战有200元经费（社联提供），购买时请保留付款记录和下单记录，方便后续报销。
			1.1.3 百团大战的活动一般以排球知识问答、垫球小挑战为主，参与挑战的同学可以领取免费奖品。
			1.1.4 活动需要准备：海报、奖品、推文
		1.2 迎新杯排球赛
			1.2.1 迎新杯排球赛时间一般在期中前，但不宜过早，比赛日共四天，赛制为大循环
			1.2.2 赛前准备事项
				1.2.2.0 在迎新杯比赛的计划时间2-3周前就准备好规程、各队报名表、赛程表、积分表，协调红会安全保障、志愿者联的志愿服务。
				1.2.2.1 规程在往年基础上修改，注意重新调整赛程。（只需随机指定A-G到各队之间的映射关系就可以）
				1.2.2.2 报名表上的“队长签名”可以用电子签。
				1.2.2.3 注意只有报名表上的队员可以上场比赛，休学后复学的大二学生不允许参加迎新杯。
				1.2.2.4 红会安全保障、志愿者联的志愿服务直接邮件联系。
				1.2.2.5 积分表与计分表不同，前者是用来记录队伍之间胜负情况及积分的，制作完成后及时跟侯思宇老师联系，制作积分板。
				1.2.2.6 迎新杯比赛的现场海报、横幅的制作由体育中心负责，但务必跟侯思宇老师提前联系，避免比赛开始了还没有现场海报。
				1.2.2.7 奖状和奖杯的制作需联系侯思宇老师。
				1.2.2.8 奖项设置：团体总分冠军，团体冠军，团体亚军，团体季军，道德风尚奖（3个或4个），最佳组织奖（个人奖项，1个），最有价值球员奖（个人奖项 ，1个）
					1.2.2.8.1 团体总分冠军即积分最高的冠军。
					1.2.2.8.2 如果研究生队获得总分冠军，则排名2、3、4的三个书院队分获冠亚季，剩余3个队伍获得道德风尚。
					1.2.2.8.3 如果书院队伍获得总分冠军，则它同时获得冠军，排名2、3的两个队伍分获亚军、季军。剩余4个队伍获得道德风尚。
					1.2.2.8.4 最佳组织奖颁给在这次活动的组织中出力最多者。
					1.2.2.8.5 最有价值球员奖颁给表现最亮眼的冠亚队伍成员。（一般为大二队员，且其最好同时是校队成员；如有表现尤其突出的大一队员，可有例外）
				1.2.2.9 比赛规程和报名表是正式文件，侯思宇老师会印出秩序册和纸质报名表并且盖上体育中心的章，盖章的文件请扫描/拍照发给各队队长。
			1.2.3 比赛采用简化版记分表，在赛前按照“比赛场次 + 10”的数量印记分表。
				1.2.3.1 计分表使用教程在b站上有。
				1.2.3.2 计分表务必妥善保管，不得让别人随意修改，后续志愿时的认证，计分表上的裁判签到情况是重要依据。
			1.2.4 裁判事宜
				1.2.4.1 裁判包括主裁、二裁、司线(1-4位)、记分员(1-2位)
				1.2.4.2 裁判通常由志愿者担任，志愿者一般由排球爱好者们报名并且担任，不了解排球的志愿者可以担任司线、记分员等。
				1.2.4.3 志愿者联明面规定：志愿者不能担任裁判工作，因此在与志愿者联的负责人沟通及各类申请文件、材料中时请避免“裁判”字眼，用“维护场地秩序”等字眼代替即可。
				1.2.4.4 在大的志愿者群聊中，也不得提到裁判工作，后续通过设计问卷的形式筛选志愿者(问卷内容自定义，但要不能让别的志愿者起疑心)
				1.2.4.5 在筛选时要求志愿者填写义工号。
				1.2.4.6 筛选志愿者后将志愿者拉入正式群中，务必保证 **正式群聊** 中没有志愿者联的工作人员
				1.2.4.7 在正式群中发布共享表格，让志愿者自选工作时间及岗位。
				1.2.4.8 比赛现场严格组织志愿者签到，可以让主裁、记分员提醒其他志愿者在计分表上签名。
				1.2.4.9 请留存一部分志愿者工作照片。（不要有包含裁判工作的照片，但可以是扫地、搬水、组织签到等）
				1.2.4.10 迎新杯结束后及时暂停表格共享，表格中如果有空位，自行处理（你懂我的意思）。
				1.2.4.11 比赛结束后一周内按照实际签到情况统计志愿者的总时长（一场按照1.5小时计算），excel的SUMIF函数很方便。
				1.2.4.12 统计后向志愿者公示，确认无误。
				1.2.4.13 向志愿者联邮件提交总时长表格、志愿者工作照片。
				1.2.4.14 义工时完成认证后，在群众通知全体成员，后续解散群聊。
			1.2.5 宣传事务
				1.2.5.1 一般情况下需要制作一篇赛中报道推文（与南方科技大学体育运动协会合作）和一篇赛后总结推文。
				1.2.5.2 推文内容及模板在往年内容基础上增加、删改即可。
				1.2.5.3 比赛过程中可以多拍照片，或者联系各队队长自己留存影像记录。
				1.2.5.4 有条件可以全场录像。
				1.2.5.5 推文的credit务必明确，不可漏人。
				1.2.5.6 宣传海报不是硬性要求。
			1.2.6 完赛后事务
				1.2.6.1 一般第四个比赛日的下午3点最后一场比赛结束，5点颁奖典礼。
				1.2.6.2 在最后一场比赛和颁奖典礼之间的两个小时填写好奖状。
				1.2.6.3 颁奖典礼要拍合照。
				1.2.6.4 发布推文。（可以跟体协一起写）
